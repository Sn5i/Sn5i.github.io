    The story

    About the app

    Snow's Widgets started as one folder of apps on a taskbar. It grew into a full widget bar: a clipping engine built on OBS, a Start menu companion, Twitch alerts and a lot of pixel snow. Every version was tested on real gaming PCs, AMD and NVIDIA.

    It's free and open source, so anyone can read the code, learn from it, or help make it better.

    Questions

    FAQ

    Is it really free?

    Yes. No ads, no account, no paid version. The full source code is on GitHub.

    Is it safe?

    The installer is scanned clean by 68 antivirus engines on VirusTotal, the code is public, and installers are built by GitHub from that public code. The app sends no data about you anywhere.

    Will clipping slow down my games?

    Very little. It records with your graphics card's video encoder (AMD, NVIDIA or Intel), the same way OBS and ShadowPlay do, and it never upscales.

    Which PCs does it work on?

    Windows 10 and 11, 64-bit. Clipping works on AMD, NVIDIA and Intel graphics, and falls back to the CPU if needed.

    How do I update?

    You don't have to do anything. The app checks for new versions and shows "Update and restart" when one is ready.
